# 提出物チェッカー（高校英語・複数クラス対応）

出した生徒の番号を押すだけで、まだ出していない生徒が「3・7・12番」のようにすぐ分かる提出物チェックアプリです。
教科担任として複数クラスを持つ高校の英語の先生向けに、ワークブック・英作文・単語テスト直し・音読カードなどの課題点検を想定しています。

記録するのは「出したか、まだか」だけです。評価や点数を書く欄はありません。名前を入れなくても、出席番号だけで動きます。

## できること

| 画面 | 内容 |
| --- | --- |
| 回収状況 | 今日が締切の提出物を上に表示。提出物×クラスごとのカードを「回収中／あと5人以下／締切超過／全員提出」の色で表示。締切順・未提出が多い順・クラスごと・提出物ごとに並べ替え |
| チェック入力 | 縦に出席番号、横に提出物。マスを押すと ✓。「番号で入力」で番号＋Enterを続けて入力。取り消し、完了した提出物を隠す、未提出のある番号だけ表示 |
| 声かけビュー | 未提出を生徒ごとにまとめて表示（例：「3番：ワークブック、英作文」）。生徒ごと・クラスごとにコピー。未提出が2件以上重なる番号の「要注意リスト」 |
| 印刷プレビュー | クラス別（掲示用）・個人別（4人分／A4、切って渡す）・白紙のチェック表をA4で印刷／PDF保存 |
| 提出物 | 提出物の追加・編集・削除（提出物名は英語課題の候補から選べる。対象クラスは複数選択可。伝えた日・締切）。クラス設定（最大10クラス、1クラス45人まで、名前は任意） |
| 使い方 | アプリ内の説明 |

## 使い方は2通り

### A. Googleスプレッドシートで使う（おすすめ・記事と同じ形）

データはそのスプレッドシートの中に保存されます。学校のGoogleアカウントで使えば、PCでもタブレットでも同じデータを見られます。

1. Googleドライブで新しいスプレッドシートを作ります（名前は「提出物チェッカー」など）。
2. メニュー「拡張機能」→「Apps Script」を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このリポジトリの [`gas/Code.gs`](gas/Code.gs) の中身を貼り付けます。
4. 左の「ファイル」の「＋」→「HTML」で、名前を **`index`** にしてファイルを作り、中身をすべて消して [`index.html`](index.html) の中身を貼り付けます。
5. 保存（Ctrl+S / ⌘+S）して、スプレッドシートのタブに戻り、ページを再読み込みします。
6. 上部に「⚙ 提出物チェッカー」メニューが出たら、「提出物チェッカーを開く」を押します。
   初回はGoogleの許可画面が出ます。学校のアカウントで止められた場合は、無理に進めずICT担当の先生に相談してください。
7. 「1クラスで使う／複数クラスで使う／サンプルで試してみる」を選びます。
8. 「提出物」画面の「クラス設定」でクラス名と人数を入れて保存すると、クラスごとのシートが自動で作られます。
   （「設定」シートに直接入力して、メニュー「クラスシートを生成」を実行しても同じです。）

メニュー
- **提出物チェッカーを開く** … スプレッドシートの上にアプリを開きます（デプロイ不要）
- **クラスシートを生成** … 「設定」シートの内容からクラスシートを作ります
- **サンプルデータを消して初期化** … すべてのクラス・提出物・チェック記録を消します

URLから直接開きたい場合は、Apps Scriptの「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」でデプロイしてください（実行ユーザー：自分、アクセス：自分のみ を推奨）。

シートの構成
- `設定` … A列クラス名、B列人数
- `提出物` … ID／提出物名／対象クラス／伝えた日／締切／作成日時
- クラス名のシート … 番号、氏名（任意）、提出物ごとの列（✓＝提出）。2行目は提出物IDの非表示行なので消さないでください。

### B. ブラウザだけで使う

[`index.html`](index.html) をダウンロードしてブラウザで開くだけでも動きます。データはその端末のブラウザの中だけに保存されます。
端末を替えるときやブラウザのデータを消す前に、「提出物」画面の「データ」→「バックアップを保存」でJSONを保存してください。

## 安心して使うために

- クラス・提出物・チェック状況を、外部へ送る仕組みはありません。
- サンプルデータ（2年1〜3組、英語の提出物）はすべて架空です。「サンプルデータを消して初期化」で消せます。
- 名前を入れるかどうかは、学校のルールに合わせて判断してください。番号だけで、チェック・声かけ・印刷まで使えます。
