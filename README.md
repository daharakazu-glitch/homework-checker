# 提出物チェッカー（高校英語・複数クラス対応）

出した生徒の番号を押すだけで、まだ出していない生徒が「3・7・12番」のようにすぐ分かる提出物チェックアプリです。
教科担任として複数クラスを持つ高校の英語の先生向けに、ワークブック・英作文・単語テスト直し・音読カードなどの課題点検を想定しています。

## 使い方は2通り

### おすすめ：複数の端末で使う（Googleアカウントで同期）

**設定手順：https://daharakazu-glitch.github.io/homework-checker/setup.html**

最初に1回だけ、約5分の設定をします（プログラムをコピー → script.google.com に貼り付け → ウェブアプリとしてデプロイ）。
設定後は、同じGoogleアカウントでログインしていれば、パソコン・iPad・Chromebookのどれからでも、ブックマークしたURLを開くだけで同じデータを使えます。

- データは、あなたのGoogleドライブに自動で作られるスプレッドシート「提出物チェッカー データ」に保存されます。外部へは送信されません。
- 「アクセスできるユーザー：自分のみ」でデプロイするので、URLをほかの人が開いてもデータは見られません。
- ほかの端末で入力した内容は、画面右上の「↻ 最新に更新」で読み込めます（しばらく別の画面にいて戻ってきたときは自動で読み込みます）。

### お試し：URLを開くだけ（この端末だけで使う）

**https://daharakazu-glitch.github.io/homework-checker/**

設定なしですぐ使えますが、データはその端末のそのブラウザの中だけに保存されます。
あとから同期版に移るときは、「提出物」→「データ」→「バックアップを保存」したファイルを、同期版の「バックアップから復元」で読み込みます。

## できること

| 画面 | 内容 |
| --- | --- |
| 回収状況 | 今日が締切の提出物を上に表示。提出物×クラスごとのカードを「回収中／あと5人以下／締切超過／全員提出」の色で表示。締切順・未提出が多い順・クラスごと・提出物ごとに並べ替え |
| チェック入力 | 縦に出席番号、横に提出物。マスを押すと ✓。「番号で入力」で番号＋Enterを続けて入力。取り消し、完了した提出物を隠す、未提出のある番号だけ表示 |
| 声かけビュー | 未提出を生徒ごとにまとめて表示（例：「3番：ワークブック、英作文」）。生徒ごと・クラスごとにコピー。未提出が2件以上重なる番号の「要注意リスト」 |
| 印刷プレビュー | クラス別（掲示用）・個人別（4人分／A4、切って渡す）・白紙のチェック表をA4で印刷／PDF保存 |
| 提出物 | 提出物の追加・編集・削除（英語課題の候補から選べる。対象クラスは複数選択可。伝えた日・締切）。クラス設定（最大10クラス、1クラス45人まで、名前は任意）。バックアップ・復元 |
| 使い方 | アプリ内の説明 |

記録するのは「出したか、まだか」だけです。評価や点数を書く欄はありません。名前を入れるかどうかは、学校のルールに合わせて判断してください。

## ファイル構成（管理者向け）

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリの画面。単体ではブラウザ保存、Apps Script上ではスプレッドシート保存で動く |
| `setup.html` | 同期版の設定手順ページ（プログラムのコピーボタン付き） |
| `gas/server.gs` | Apps Script のサーバー側の処理（データ用スプレッドシートの自動作成・読み書き） |
| `gas/teishutsu-checker.gs` | 貼り付け用の1ファイル版。`node tools/build-gas.js` で `gas/server.gs` と `index.html` から生成する（直接編集しない） |

`index.html` や `gas/server.gs` を変更したら、`node tools/build-gas.js` を実行して `gas/teishutsu-checker.gs` も更新してください。

### 公開の設定（最初に1回だけ）

GitHubの「Settings」→「Pages」で、Source を **Deploy from a branch**、Branch を **main** / **/ (root)** にして保存すると、上のURLで公開されます。
