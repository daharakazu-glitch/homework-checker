# 提出物チェッカー（高校英語・複数クラス対応）

出した生徒の番号を押すだけで、まだ出していない生徒が「3・7・12番」のようにすぐ分かる提出物チェックアプリです。
教科担任として複数クラスを持つ高校の英語の先生向けに、ワークブック・英作文・単語テスト直し・音読カードなどの課題点検を想定しています。

## 使い方：URLを開くだけ

**https://daharakazu-glitch.github.io/homework-checker/**

インストールやGoogleの許可は不要です。パソコン・iPad・Chromebookのブラウザで開けば、そのまま使えます。

1. 上のURLを開きます（よく使う端末でブックマーク、またはiPadなら「ホーム画面に追加」しておくと便利です）。
2. 「1クラスで使う」「複数クラスで使う」「サンプルで試してみる」のどれかを選びます。
3. 「提出物」画面の下にある「クラス設定」で、クラス名と人数を入れて保存します（名前は入れなくても使えます）。
4. 「提出物」→「＋ 追加」で、今日集める提出物を一つ登録します。
5. 「チェック入力」で、出した子の番号のマスを押します。残っている番号は「回収状況」「声かけビュー」で確認できます。

### データの保存について

- データは **その端末のそのブラウザの中だけ** に保存されます。外部へは送信されません。
- 別の端末やブラウザで開くと、データは空の状態です。いつも同じ端末・同じブラウザで開いてください。
- 端末の故障やブラウザのデータ消去に備えて、「提出物」画面の下にある「データ」→「バックアップを保存」でときどきファイルを保存してください（14日以上バックアップしていないと、回収状況の画面にお知らせが出ます）。
- 別の端末に移すときは、バックアップファイルを「バックアップから復元」で読み込みます。

## できること

| 画面 | 内容 |
| --- | --- |
| 回収状況 | 今日が締切の提出物を上に表示。提出物×クラスごとのカードを「回収中／あと5人以下／締切超過／全員提出」の色で表示。締切順・未提出が多い順・クラスごと・提出物ごとに並べ替え |
| チェック入力 | 縦に出席番号、横に提出物。マスを押すと ✓。「番号で入力」で番号＋Enterを続けて入力。取り消し、完了した提出物を隠す、未提出のある番号だけ表示 |
| 声かけビュー | 未提出を生徒ごとにまとめて表示（例：「3番：ワークブック、英作文」）。生徒ごと・クラスごとにコピー。未提出が2件以上重なる番号の「要注意リスト」 |
| 印刷プレビュー | クラス別（掲示用）・個人別（4人分／A4、切って渡す）・白紙のチェック表をA4で印刷／PDF保存 |
| 提出物 | 提出物の追加・編集・削除（英語課題の候補から選べる。対象クラスは複数選択可。伝えた日・締切）。クラス設定（最大10クラス、1クラス45人まで、名前は任意）。バックアップ |
| 使い方 | アプリ内の説明 |

記録するのは「出したか、まだか」だけです。評価や点数を書く欄はありません。名前を入れるかどうかは、学校のルールに合わせて判断してください。

## 公開の設定（リポジトリの管理者が最初に1回だけ）

上のURLで開けるようにするには、GitHub Pages を有効にします。

1. GitHubでこのリポジトリを開き、「Settings」→ 左メニューの「Pages」を開きます。
2. 「Build and deployment」の「Source」で **Deploy from a branch** を選びます。
3. 「Branch」で **main** と **/ (root)** を選び、「Save」を押します。
4. 1〜2分後に https://daharakazu-glitch.github.io/homework-checker/ で開けるようになります。

以降は `main` の `index.html` を更新すると、公開中のアプリも自動で更新されます。

## （上級者向け）Googleスプレッドシートにデータを保存したい場合

複数の端末で同じデータを使いたい場合は、Googleスプレッドシート＋Apps Scriptでも動かせます。

1. 新しいスプレッドシートを作り、「拡張機能」→「Apps Script」を開きます。
2. `コード.gs` の中身を [`gas/Code.gs`](gas/Code.gs) に置き換えます。
3. 「＋」→「HTML」で名前を **`index`** にしたファイルを作り、[`index.html`](index.html) の中身を貼り付けます。
4. 保存してスプレッドシートを再読み込みし、「⚙ 提出物チェッカー」→「提出物チェッカーを開く」を選びます（初回はGoogleの許可画面が出ます）。

データは「設定」「提出物」シートとクラスごとのシートに保存されます。
