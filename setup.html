提出物チェッカーを校内で使う

1人の先生（管理する先生）が最初に1回だけ設定し、できたURLを校内の先生に配ります。配られた先生は、URLを開いて許可するだけで使えます。データは先生ごとに、その先生のGoogleドライブに別々に保存され、メールもその先生のGmailから送られます。ほかの先生のデータが見えることはありません。

配られたURLで使う先生へ

★URLを開いて許可するだけ

  1. パソコン・iPad・Chromebookのブラウザで、学校のGoogleアカウントでログインした状態で 配られたURLを開きます。
  2. 初回だけ許可の画面が出ます。許可 を押してください（データ用のスプレッドシートの作成と、生徒へのメール送信に使います）。
  3. 「1クラスで使う／複数クラスで使う」を選び、「提出物」画面の下の「クラス設定」でクラスを登録すれば使い始められます。URLはブックマークしておきましょう。
ブラウザで学校とプライベートなど複数のGoogleアカウントにログインしていると、「ファイルを開くことができません」などと表示されて開けないことがあります。そのときは、シークレットウィンドウ（Ctrl+Shift+N）で学校のアカウントだけでログインして開くか、Chromeに学校用のプロフィールを作って開いてください。

「提出物」→「データ」に、使用中のアカウントが表示されます。データとメールの送り主は、そのアカウントのものです。

管理する先生（最初の1人）の設定

1プログラムをコピーする

下のボタンを押すと、提出物チェッカーのプログラムがコピーされます。

うまくコピーできない場合は、こちらのページを開き、Ctrl+A（Macは⌘+A）ですべて選択してコピーしてください。

2Apps Script に貼り付ける

  1. パソコンで、学校のGoogleアカウントだけでログインした状態で script.google.com（新しいプロジェクト） を開きます（複数のアカウントでログインしていると保存できないことがあります）。
  2. 画面左上の 無題のプロジェクト を押して、名前を「提出物チェッカー」にします。
  3. 最初から入っている function myFunction() { … } をすべて消し、コピーしたプログラムを貼り付けます。
  4. 💾 保存（Ctrl+S / ⌘+S）を押します。
  5. エディタ上部の関数の選択で authorize を選び、▷ 実行 を押して許可します（一覧に出ないときはページを再読み込みしてください）。
「このアプリは Google で確認されていません」と表示されたら、詳細 → 提出物チェッカー（安全ではないページ）に移動 → 許可 と進みます。自分で作ったプログラムを動かすときに出る表示です。学校のアカウントで許可が止められた場合は、無理に進めずICT担当の先生に相談してください。

3ウェブアプリとしてデプロイする

  1. 右上の デプロイ → 新しいデプロイ を押します。
  2. 「種類の選択」の歯車 ⚙ を押し、ウェブアプリ を選びます。
  3. 次のように設定して デプロイ を押します。
    • 次のユーザーとして実行：ウェブアプリケーションにアクセスしているユーザー
    • アクセスできるユーザー：（学校名）内の全員

この設定にすると、URLを開いた先生それぞれのアカウントで動きます。学校のアカウントを持っていない人は開けません。自分1人だけで使う場合は「自分のみ」にしてもかまいません。

4URLを開いて確かめ、校内の先生に配る

  1. デプロイが終わると「ウェブアプリ」のURL（https://script.google.com/a/macros/…/exec）が表示されます。コピー して開き、使えることを確かめてブックマークします。
  2. そのURLを、校内の先生にメールやチャットで配ります。このページの「配られたURLで使う先生へ」の説明も一緒に伝えてください。

↻新しいバージョンに更新するとき（管理する先生だけ）

  1. 1・2の手順でプログラムを貼り替えて保存します（エディタの中で Ctrl+A で全部選択してから貼り付けます）。
  2. 新しい許可が必要な更新のときは、authorize を実行して許可します。
  3. デプロイ → デプロイを管理 → ✏️ 編集 → バージョン 新バージョン → デプロイ を押します。

URLは変わらず、全員に新しいバージョンが届きます。各先生のデータもそのまま残ります。

!これまで「自分のみ」で使っていた場合

すでに「次のユーザーとして実行：自分」「アクセスできるユーザー：自分のみ」で使っている場合は、URLを変えずに校内向けに切り替えられます。

  1. 新しいバージョンのプログラムに貼り替えて保存し、authorize を実行して許可します。
  2. デプロイ → デプロイを管理 → ✏️ 編集 で、手順3のとおり「実行するユーザー」と「アクセスできるユーザー」を変え、バージョン 新バージョン → デプロイ を押します。
  3. いつものURLを開き直します。これまでのデータは、データ用スプレッドシートの持ち主であるあなたが開いたときに自動で引き継がれます（ほかの先生には引き継がれません）。

✉メールで知らせる機能について

名簿に生徒のメールアドレス（Googleアカウント）を登録すると、「声かけビュー」から、未提出がある生徒一人ひとりにメールを送れます。メールは、使っている先生のGmailから送られます。

Googleの決まりで、1日に送れるメールの数には上限があります（学校のGoogle Workspaceアカウントは先生1人あたり約1,500通）。送信記録は各先生のスプレッドシートの「メール送信記録」シートに残ります。生徒へのメール連絡については、学校のルールに従ってください。

？使っているときのこと

  • 同じアカウントなら、どの端末からでも同じデータを使えます。ほかの端末で入力した内容は、画面右上の ↻ 最新に更新 で読み込めます（しばらく別の画面にいて戻ってきたときは自動で読み込みます）。
  • ブラウザ版（github.io のページ）で入力していたデータは、ブラウザ版で「バックアップを保存」→ こちらで「バックアップから復元」で引き継げます。
