複数の端末で使う設定（Googleアカウントで同期）

最初に1回だけ、約5分の設定です。設定後は、同じGoogleアカウントでログインしていれば、パソコン・iPad・Chromebookのどれからでも同じデータを使えます。データはあなたのGoogleドライブに保存され、外部へは送信されません。

1プログラムをコピーする

下のボタンを押すと、提出物チェッカーのプログラムがコピーされます。

うまくコピーできない場合は、こちらのページを開き、Ctrl+A（Macは⌘+A）ですべて選択してコピーしてください。

2Apps Script に貼り付ける

  1. パソコンで、学校のGoogleアカウントにログインした状態で script.google.com（新しいプロジェクト） を開きます。
  2. 画面左上の 無題のプロジェクト を押して、名前を「提出物チェッカー」にします。
  3. 最初から入っている function myFunction() { … } をすべて消し、コピーしたプログラムを貼り付けます。
  4. 💾 保存（Ctrl+S / ⌘+S）を押します。

3ウェブアプリとしてデプロイする

  1. 右上の デプロイ → 新しいデプロイ を押します。
  2. 「種類の選択」の歯車 ⚙ を押し、ウェブアプリ を選びます。
  3. 次のように設定して デプロイ を押します。
    • 次のユーザーとして実行：自分
    • アクセスできるユーザー：自分のみ
  4. アクセスを承認 を押し、自分のアカウントを選んで許可します。
「このアプリは Google で確認されていません」と表示されたら、詳細 → 提出物チェッカー（安全ではないページ）に移動 → 許可 と進みます。これは自分で作ったプログラムを自分のアカウントで動かすときに出る表示です。学校のアカウントで許可が止められた場合は、無理に進めずICT担当の先生に相談してください。

4表示されたURLを開いて、ブックマークする

  1. デプロイが終わると「ウェブアプリ」のURL（https://script.google.com/macros/s/…/exec）が表示されます。コピー してブラウザで開きます。
  2. 提出物チェッカーが開いたら、ブックマークしてください。初めて開いたときに、データ用のスプレッドシート「提出物チェッカー データ」がGoogleドライブに自動で作られます。
  3. iPadやほかのパソコンでも、同じGoogleアカウントでログインして このURLを開けば、同じデータを使えます。URLはメールやGoogle Keepなどで自分に送っておくと便利です。

「アクセスできるユーザー：自分のみ」にしているので、URLをほかの人が開いてもデータは見られません。

✓ブラウザ版のデータを引き継ぐ（必要な場合だけ）

これまでブラウザ版（github.io のページ）で入力していた場合は、次の手順で引き継げます。

  1. ブラウザ版で「提出物」→「データ」→ バックアップを保存。
  2. 同期版で「提出物」→「データ」→ バックアップから復元 で、そのファイルを選びます。

？使っているときのこと

  • ほかの端末で入力した内容は、画面右上の ↻ 最新に更新 で読み込めます（しばらく別の画面にいて戻ってきたときは自動で読み込みます）。
  • 新しいバージョンに更新するときは、1・2の手順でプログラムを貼り替えて保存し、デプロイ → デプロイを管理 → ✏️ 編集 → バージョン 新バージョン → デプロイ を押します。URLは変わらず、データもそのまま残ります。

✉メールで知らせる機能を使うとき

名簿に生徒のメールアドレス（Googleアカウント）を登録すると、「声かけビュー」から、未提出がある生徒一人ひとりにメールを送れます。メールは先生のGmailから送られます。

  1. Apps Script のエディタ上部で、実行する関数に authorize を選び、▷ 実行 を押します。
  2. 許可の画面が出たら、手順3と同じように進めて許可します（「メールの送信」の許可が追加されます）。
  3. すでに使っている場合は、プログラムを貼り替えたあと、この許可をしてから「新バージョン」でデプロイしてください。

Googleの決まりで、1日に送れるメールの数には上限があります（学校のGoogle Workspaceアカウントは約1,500通、個人のアカウントは約100通）。送信記録はスプレッドシートの「メール送信記録」シートに残ります。生徒へのメール連絡については、学校のルールに従ってください。
